# Contributing

Contributions, bug reports, and terminology suggestions are welcome.

CST is built for a Korean-speaking TRPG audience, especially Call of Cthulhu keepers and scenario translators working from Japanese source text. Helpful contributions include:

- Bug reports with clear reproduction steps.
- Korean UI or manual improvements.
- CoC/TRPG terminology corrections.
- Translation workflow suggestions.
- Security and release-process review.

Please do not share copyrighted scenario text, private table notes, real API keys, or other secrets in issues or pull requests.

## Development

```text
npm install
npm run check
npm start
```

Please run `npm run check` before opening a pull request.

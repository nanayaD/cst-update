# 코딩 AI 전용 지시문: 일본어 CoC 시나리오 부분 번역기 제작

## 1. 제작 목표

일본어 TRPG 시나리오, 특히 Call of Cthulhu 6판 기준으로 작성된 일본어 시나리오를 한국어로 부분 번역하는 데스크톱 프로그램을 제작한다.

이 프로그램은 전체 파일 번역기가 아니라, 사용자가 필요한 문단·장면·핸드아웃·묘사·NPC 대사·판정문을 직접 복사해 입력하면 그 부분만 번역하는 보조 도구다.

번역 결과는 일본어 원문의 의미, 정보 구조, 문체 차이를 최대한 보존하면서 한국어로 자연스럽게 읽히도록 작성되어야 한다. 또한 일본 CoC 6판 시나리오에 자주 등장하는 용어, 판정, 능력치 표기, 기능명을 감지하여 CoC 7판 기준으로 이해하기 쉽도록 참고 메모를 제공한다.

완전한 룰 컨버팅 도구가 아니라 **부분 번역 + CoC 7판 참고 메모** 도구로 설계한다.

---

## 2. 기술 스택

Electron 기반 데스크톱 앱으로 제작한다.

사용 기술은 다음을 기준으로 한다.

- Electron
- Node.js
- HTML
- CSS
- JavaScript
- OpenAI API 호출용 SDK 또는 fetch
- electron-store 또는 로컬 설정 파일을 통한 사용자 설정 저장

Windows 사용자가 실행하기 쉽도록 최종적으로 `.exe` 또는 설치 파일 형태로 빌드할 수 있어야 한다.

## 3. 기본 화면 구성

앱은 크게 다음 영역으로 구성한다.

### 3-1. 설정 영역

사용자가 프로그램 안에서 직접 API 관련 설정을 입력할 수 있어야 한다.

필수 입력 항목:

- OpenAI API Key
- 사용할 모델명
- 1회 번역 글자수 제한
- 기본 번역 모드
- CoC 7판 참고 메모 사용 여부

API 키는 앱 내부 설정창에서 입력한다. 프로그램 코드 안에 API 키를 하드코딩하지 않는다. 배포 파일에도 API 키를 포함하지 않는다.

API 키 저장 방식은 사용자의 로컬 PC에만 저장되도록 한다. 외부 서버로 전송하지 않는다.

### 3-2. 입력 영역

사용자가 일본어 원문을 붙여넣을 수 있는 큰 입력창을 만든다.

입력창에는 현재 글자수를 표시한다.

설정된 글자수 제한을 초과하면 번역 버튼을 비활성화하거나 경고를 표시한다.

예시:

```txt
현재 글자수: 1,240 / 3,000
```

제한 초과 시:

```txt
입력 글자수가 제한을 초과했습니다. 문단을 나누어 번역하세요.
```

### 3-3. 보조 메모 영역

부분 번역은 앞뒤 문맥이 잘릴 수 있으므로, 사용자가 추가 문맥을 입력할 수 있는 메모칸을 둔다.

예시 입력 항목:

- 등장인물 이름
- KPC 설명
- PC와 NPC의 관계
- 고유명사 처리 방식
- 호칭 유지 여부
- 특정 용어 번역 규칙

이 메모는 번역 요청 프롬프트에 함께 포함한다.

### 3-4. 번역 모드 선택 영역

다음 번역 모드를 버튼 또는 드롭다운으로 선택할 수 있게 한다.

1. 원문 충실 번역
2. 자연스러운 한국어 번역
3. 단서/핸드아웃 보존 번역
4. CoC 7판 참고 메모 포함 번역

각 모드는 API 요청 프롬프트가 다르게 구성되어야 한다.

### 3-5. 출력 영역

출력은 다음 섹션으로 구분한다.

- 번역문
- CoC 7판 참고 메모
- 검토 필요 항목
- 고유명사/호칭 메모

각 섹션에는 복사 버튼을 둔다.

전체 복사 버튼도 둔다.

---

## 4. 번역 모드 상세

### 4-1. 원문 충실 번역

원문의 문장 구조, 정보 순서, 조건문, 단서 표현을 최대한 보존한다.

의역을 최소화한다.

단서, 규칙, 판정 조건, 핸드아웃 번역에 적합하다.

### 4-2. 자연스러운 한국어 번역

한국어 문장으로 읽기 자연스럽게 다듬는다.

단, 원문의 정보가 누락되면 안 된다.

묘사문, NPC 대사, 장면 서술에 적합하다.

### 4-3. 단서/핸드아웃 보존 번역

암호, 편지, 일기, 신문 기사, 책 내용, 조사 자료, 핸드아웃의 정보 순서를 최대한 유지한다.

문학적으로 과도하게 다듬지 않는다.

고유명사와 특수 표현은 가능하면 원문을 병기한다.

예시:

```txt
세이토정(星灯亭)
```

### 4-4. CoC 7판 참고 메모 포함 번역

일본어 CoC 6판 시나리오의 표현을 감지하고, 한국어 CoC 7판 기준으로 이해하기 쉬운 참고 메모를 함께 출력한다.

기능명, 판정명, 능력치 표기, 배수 판정, 아이디어 롤 등을 7판 기준으로 참고 변환한다.

애매한 항목은 자동 확정하지 말고 `[검토 필요]`로 표시한다.

## 5. CoC 7판 참고 메모 규칙

CoC 6판 기준 일본어 시나리오를 번역할 때, 7판 기준으로 참고할 만한 차이가 감지되면 번역문과 별도로 참고 메모를 출력한다.

이 기능은 번역문 자체를 과도하게 바꾸기 위한 것이 아니라, 사용자가 6판 표현을 7판 기준으로 이해하거나 조정할 수 있도록 보조 메모를 제공하는 기능이다.

### 5-1. 특성치 표기 참고 변환

6판식 특성치가 감지되면 7판식 백분율 표기로 참고 변환한다.

기본 원칙은 6판 수치에 5를 곱하는 것이다.

예시:

```txt
STR 12 → 근력 60
CON 13 → 건강 65
POW 14 → 정신력 70
DEX 11 → 민첩 55
APP 10 → 외모 50
SIZ 15 → 크기 75
INT 16 → 지능 80
EDU 17 → 교육 85
```

변환은 참고 메모로 제공한다. 번역문 본문에서는 원문 수치의 의미가 훼손되지 않도록 주의한다.

HP, MP, 피해 보너스, 체구, 이동력, 전투 관련 세부 수치는 단순 ×5 변환으로 확정하지 말고 검토 필요 항목으로 표시한다.

### 5-2. 기능명 참고 변환

CoC 6판 기능명 또는 일본어 시나리오에서 자주 쓰이는 기능명이 감지되면 7판 기준 한국어 용어로 참고 변환한다.

예시:

```txt
目星 → 관찰력
聞き耳 → 듣기
図書館 → 자료조사
アイデア → 지능 판정
幸運 → 행운
心理学 → 심리학
説得 → 설득
信用 → 신용
言いくるめ → 말재주
回避 → 회피
応急手当 → 응급처치
医学 → 의학
オカルト → 오컬트
歴史 → 역사
博物学 → 자연
```

다음 기능은 7판 기준에서 1:1 대응이 애매할 수 있으므로 검토 필요로 표시한다.

```txt
隠れる → 은밀행동 계열로 검토 필요
忍び歩き → 은밀행동 계열로 검토 필요
```

### 5-3. 전투 기술 통합 관련 메모

6판에서는 주먹질, 발차기, 박치기, 붙잡기 등 전투 기능이 분리되어 등장할 수 있다.

다음과 같은 표현이 감지되면 7판에서는 근접전 계열로 통합 검토가 필요하다는 메모를 출력한다.

```txt
こぶし
パンチ
キック
頭突き
組み付き
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 원문에 6판식 세부 전투 기능이 포함되어 있습니다. 7판에서는 근접전 계열로 통합하여 검토할 수 있습니다.
```

피해량, 피해 보너스, 전투 순서, 회피 처리 등은 자동 확정하지 말고 검토 필요로 표시한다.

### 5-4. 판정 난이도 관련 메모

7판에서는 판정 결과를 다음 성공 수준으로 구분한다.

```txt
보통 성공: 기능치 이하
어려운 성공: 기능치의 1/2 이하
극단적 성공: 기능치의 1/5 이하
대성공: 일반적으로 1
대실패/펌블: 일반적으로 100, 상황에 따라 96~99도 해당 가능
```

일본어 원문에 다음과 같은 표현이 등장하면 판정 난이도 관련 메모를 출력한다.

```txt
普通の成功
ハード成功
イクストリーム成功
困難な成功
極限の成功
クリティカル
ファンブル
大成功
大失敗
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 판정 난이도 표현이 감지되었습니다. 7판 기준에서는 보통 성공 / 어려운 성공 / 극단적 성공으로 구분할 수 있습니다.
```

### 5-5. 보너스/패널티 주사위 관련 메모

7판에는 보너스 주사위와 패널티 주사위 개념이 있으므로, 다음 표현이 감지되면 참고 메모를 출력한다.

```txt
ボーナス・ダイス
ボーナスダイス
ペナルティ・ダイス
ペナルティダイス
ボーナス
ペナルティ
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 보너스/패널티 주사위 표현이 감지되었습니다. 7판에서는 십의 자리 주사위를 추가로 굴려 유리하거나 불리한 값을 채택합니다.
```

### 5-6. 강행 판정 관련 메모

다음 표현이 감지되면 7판의 강행 판정 관련 메모를 출력한다.

```txt
プッシュ・ロール
プッシュロール
押し込みロール
再挑戦
もう一度判定
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 강행 판정에 해당할 수 있는 표현이 감지되었습니다. 7판에서는 같은 목표에 대해 다시 판정할 수 있지만, 실패 시 추가적인 불리한 결과가 발생할 수 있습니다.
```

단순한 재시도인지 강행 판정인지 문맥상 불확실한 경우에는 검토 필요로 표시한다.

### 5-7. 행운 소비 관련 메모

다음 표현이 감지되면 7판의 행운 소비 관련 메모를 출력한다.

```txt
幸運を消費
幸運ポイントを使う
幸運を使う
ラックを使う
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 행운 소비 관련 표현이 감지되었습니다. 7판에서는 행운을 소비해 주사위 결과를 조정할 수 있습니다.
```

### 5-8. 명백한 단서 관련 메모

시나리오 진행에 필수적인 단서가 판정 실패로 인해 사라질 수 있는 문맥이 감지되면, 명백한 단서 처리 가능성을 참고 메모로 출력한다.

감지할 표현 예시:

```txt
重要な手がかり
必ず見つかる
探索者は気づく
判定なしで分かる
自動的に分かる
明らかな手がかり
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 진행 필수 단서로 보이는 정보가 감지되었습니다. 7판에서는 명백한 단서로 처리할 수 있는지 검토할 수 있습니다.
```

### 5-9. 대항 판정 관련 메모

6판식 저항표 또는 대항 판정 표현이 감지되면 7판 기준의 성공 수준 비교 메모를 출력한다.

감지할 표현 예시:

```txt
抵抗表
対抗ロール
対抗判定
STR対SIZ
POW対POW
```

출력 예시:

```txt
[CoC 7판 참고 메모]
- 6판식 저항표 또는 대항 판정 표현이 감지되었습니다. 7판에서는 성공 수준을 비교하여 처리합니다. 성공 수준이 같으면 관련 기능치가 높은 쪽을 우선할 수 있습니다.
```

### 5-10. 검토 필요 항목

다음 항목은 자동 변환을 확정하지 말고 검토 필요로 표시한다.

- 전투 관련 수치
- 피해량
- 피해 보너스
- 체구
- 이동력
- 광기 처리
- 추격 규칙
- 주문
- 크리처 스탯
- 대항 판정
- 6판 전용 기능이 7판 기능과 1:1 대응되지 않는 경우
- 단서 제공 방식이 시나리오 진행에 직접 영향을 주는 경우

출력 예시:

```txt
[검토 필요]
- NPC 스탯의 피해 보너스, 체구, 이동력은 7판 기준으로 수동 확인이 필요합니다.
- 6판식 전투 기능이 포함되어 있습니다. 7판 근접전 기능으로 통합할지 검토하세요.
- 저항표 기반 대항 판정이 포함되어 있습니다. 7판 성공 수준 비교 방식으로 재검토하세요.
```

## 6. 프롬프트 설계

API에 보낼 프롬프트는 사용자가 선택한 모드에 따라 달라져야 한다.

공통 시스템 지시는 다음 원칙을 포함한다.

- 입력된 일본어 텍스트를 한국어로 번역한다.
- 대상은 일본어 TRPG 시나리오다.
- 원문의 정보 구조, 문체, 조건문, 단서성을 보존한다.
- 원문에 없는 정보를 임의로 추가하지 않는다.
- 불확실한 변환은 확정하지 말고 “검토 필요”로 표시한다.
- 고유명사는 가능하면 한국어 표기와 일본어 원문을 병기한다.
- 호칭은 관계성 정보이므로 함부로 삭제하지 않는다.
- CoC 6판 표현이 감지되면 7판 기준으로 이해하기 쉬운 참고 메모를 추가한다.

## 7. 출력 형식

API 응답은 가능하면 구조화된 텍스트로 받는다.

기본 출력 형식은 다음과 같다.

```txt
[번역문]
...

[CoC 7판 참고 메모]
...

[검토 필요]
...

[고유명사/호칭 메모]
...
```

사용자가 “원문 충실 번역” 또는 “자연스러운 한국어 번역”을 선택한 경우에는 CoC 7판 참고 메모를 간략히 하거나 생략할 수 있다.

사용자가 “CoC 7판 참고 메모 포함 번역”을 선택한 경우에는 반드시 CoC 7판 참고 메모와 검토 필요 항목을 분리한다.

---

## 8. 용어집 기능

기본 용어집을 프로그램 안에 포함한다.

사용자가 용어집을 수정할 수 있게 한다.

용어집 항목은 다음 구조를 가진다.

- 일본어 원문
- 한국어 번역어
- 설명
- 강제 적용 여부

예시:

```json
{
  "source": "目星",
  "target": "관찰력",
  "note": "CoC 7판 기준 기능명",
  "force": true
}
```

번역 요청 시 용어집 내용을 프롬프트에 포함한다.

---

## 9. API 키와 보안

프로그램 코드에 API 키를 넣지 않는다.

배포 시 API 키는 비워 둔다.

사용자는 설정 화면에서 자기 API 키를 직접 입력한다.

API 키는 사용자의 로컬 PC에만 저장한다.

API 키를 제작자 서버나 외부 서버로 보내는 기능을 만들지 않는다.

앱은 사용자의 입력 텍스트와 API 키를 OpenAI API 호출 이외의 목적으로 저장하거나 전송하지 않는다.

번역 기록 저장 기능은 선택 사항으로 두고, 기본값은 꺼둔다.

- 너무 긴 입력 경고
- 모델 선택 기능
- 번역 실행 전 예상 토큰이 많을 수 있다는 경고
- 연속 클릭 방지
- 번역 중 버튼 비활성화

## 11. 최소 기능 MVP

먼저 다음 기능만 구현한다.

1. Electron 앱 실행
2. API 키 설정창
3. 일본어 원문 입력창
4. 글자수 카운터
5. 번역 모드 선택
6. 번역 실행
7. 결과 출력

9. CoC 7판 참고 메모 출력

MVP 이후에 다음 기능을 추가한다.

- 번역 기록
- 프롬프트 템플릿 편집
- 모델별 설정 저장
- 다크 모드
- 출력 서식 커스터마이즈

## 12. 개발 시 주의

처음부터 복잡한 기능을 모두 넣지 말고 MVP를 먼저 완성한다.

UI는 단순하고 명확하게 만든다.

번역 버튼을 눌렀을 때 앱이 멈추지 않도록 비동기 처리한다.

API 오류, 키 오류, 네트워크 오류, 입력 초과 오류를 사용자에게 이해하기 쉽게 표시한다.

오류 메시지는 다음처럼 표시한다.

- API 키가 설정되지 않았습니다.
- 입력 글자수가 제한을 초과했습니다.
- 번역 요청 중 오류가 발생했습니다.
- 모델명을 확인하세요.
- 네트워크 연결을 확인하세요.

## 13. 최종 목표

이 프로그램은 일본어 CoC 시나리오를 한국어로 부분 번역하고, 필요한 경우 CoC 6판 표현을 7판 기준으로 이해하기 쉽게 참고 메모로 제공하는 도구다.

핵심은 다음 세 가지다.

1. 일본어 원문을 정확히 번역한다.
2. 문체, 고유명사, 호칭, 단서성을 보존한다.
3. CoC 6판 표현에 대해 CoC 7판 참고 메모를 제공한다.

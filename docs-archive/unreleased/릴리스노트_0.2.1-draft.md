# CST 0.2.1 릴리스 노트

**CST (CoC JP Scenario Translator)**
배포일: 2026-06-01 · 배포 파일: `CST-0.2.1-portable.exe` (Windows 무설치판)

---

## 무엇이 바뀌었나

이번 0.2.1은 **설정·로그가 저장되는 폴더 이름을 `CST`로 정리**한 유지보수 버전입니다.

- 기존(0.2.0)에는 설정·로그 폴더가 정식 이름인 `coc-jp-scenario-translator`로 만들어졌습니다. 이제 프로그램명과 동일하게 **`Roaming\CST`** 폴더를 사용합니다.
- **기존 사용자 자동 이전(마이그레이션):** 0.2.0을 쓰던 분이 0.2.1을 처음 실행하면, 옛 폴더의 설정과 API 키를 새 `CST` 폴더로 **자동 복사**합니다. **API 키를 다시 입력할 필요가 없습니다.**
- 옛 폴더(`coc-jp-scenario-translator`)는 그대로 남습니다. 정상 동작을 확인한 뒤 직접 삭제해도 됩니다.

## 업데이트 방법

- **0.2.0 사용자:** 프로그램을 실행하면 새 버전 안내가 뜹니다. 안내에 따라 `CST-0.2.1-portable.exe`를 받아, 프로그램을 완전히 종료한 뒤 기존 exe를 교체하면 됩니다. 설정·키는 자동으로 이전됩니다.
- **신규 사용자:** `CST-0.2.1-portable.exe`를 받아 실행하면 됩니다. 처음부터 `CST` 폴더를 사용합니다.

## 참고

- 0.2.0의 기능(번역기 / 문맥교정기 / OpenAI·Gemini 선택 / 자동 업데이트 확인 등)은 그대로입니다. 기능 추가·변경 없이 폴더 정리와 마이그레이션만 적용했습니다.
- 설정·키는 본인 PC의 `Roaming\CST`에만 저장되며, exe에는 포함되지 않습니다.

# CoC JP Scenario Translator 사용설명서

작성일: 2026-05-31

## 1. 프로그램 개요

CoC JP Scenario Translator는 일본어 Call of Cthulhu 시나리오 일부를 한국어로 번역하는 보조 프로그램입니다. 문단, 장면 묘사, NPC 대사, 핸드아웃, 판정문처럼 필요한 부분을 복사해 붙여넣고 번역하는 방식으로 사용합니다.

번역 결과는 기본적으로 다음 항목으로 나뉩니다.

- 번역문
- CoC 7판 참고 메모
- 검토 필요 항목
- 고유명사/호칭 메모

이 프로그램은 OpenAI와 Gemini 중 하나를 선택해 번역 요청을 보낼 수 있습니다.

또한 상단의 `번역기 / 문맥교정기` 버튼으로 두 가지 도구를 전환할 수 있습니다. `번역기`는 일본어 원문을 한국어로 번역하는 도구이고, `문맥교정기`는 이미 한국어로 된 시나리오 문장(번역 결과 포함)을 GM이 읽기 좋게 다듬거나 지칭을 정리하는 도구입니다. 두 도구는 같은 API 제공사·키·모델 설정을 공유합니다. 문맥 교정기 사용법은 10절을 참고하세요.

사용자는 선택한 제공사의 API 키를 직접 준비합니다.

OpenAI API 키는 OpenAI Platform에서 만들고, Gemini API 키는 Google AI Studio에서 만듭니다.

각 제공사의 계정, API 키, 사용량, 결제 설정은 각 제공사 페이지에서 관리합니다.

Gemini API는 Free Tier에서 특정 모델을 모델별 제한 안에서 사용할 수 있습니다.

Gemini Free Tier의 데이터 처리 조건은 Google AI Studio와 Gemini API 안내를 기준으로 확인합니다.

## 2. API 키 발급 따라하기

API 키는 이 프로그램이 OpenAI 또는 Gemini에 번역을 요청할 때 쓰는 본인 전용 인증키입니다. 둘 중 하나만 있으면 됩니다. 무료로 가볍게 시작하려면 Gemini, ChatGPT 계열 모델을 쓰려면 OpenAI를 고르세요. 아래 순서를 그대로 따라 하면 됩니다.

참고: 웹·앱에서 쓰는 ChatGPT / Gemini 구독과 API 키는 별개입니다. 구독 중이어도 API는 따로 발급·결제해야 합니다. 프로그램에 입력하는 값은 계정 비밀번호가 아니라 발급받은 API 키입니다.


A. Gemini 키 발급 (무료로 시작하기 좋음)

1. 브라우저에서 aistudio.google.com 에 접속해 Google 계정으로 로그인합니다. (처음이면 약관에 동의)
2. 왼쪽/상단의 Get API key(또는 API Keys) 메뉴를 누릅니다. 바로 가려면 aistudio.google.com/app/apikey 로 접속해도 됩니다.
3. Create API key 버튼을 누릅니다.
4. 프로젝트를 고르는 화면이 나오면 Create API key in new project(새 프로젝트에 만들기)를 선택합니다. 처음이라면 자동으로 만들어지는 프로젝트를 그대로 쓰면 됩니다.
5. AIza… 로 시작하는 긴 키가 나타나면 Copy로 복사합니다.
6. 키 목록에서 경고 배너나 Restrict key 옵션이 보이면 Restrict to Gemini API(Gemini API 전용)로 제한해 둡니다. (악용 방지, 권장)

참고: Gemini는 새 계정이 무료 Free Tier로 시작합니다. 가볍게 쓰려면 gemini-2.5-flash 같은 Flash 모델을 권장합니다. 무료 한도(분당·일일 요청 수)를 넘으면 결제 연결이 필요할 수 있습니다.


B. OpenAI 키 발급

1. 브라우저에서 platform.openai.com 에 접속해 로그인합니다. (chatgpt.com이 아니라 platform.openai.com 화면이어야 합니다.)
2. 먼저 결제를 준비합니다. 왼쪽 메뉴 Billing → Add payment method로 카드를 등록하고, 소액 크레딧(예: 5달러)을 충전합니다. Auto recharge(자동 충전)는 꺼 두는 것을 권장합니다. (선불카드는 사용 불가)
3. 왼쪽 메뉴 API keys 로 이동합니다.
4. Create new secret key 를 누르고, 알아보기 쉬운 이름(예: coc-translator)을 적습니다.
5. 권한은 가능하면 Restricted를 고릅니다. 잘 모르겠으면 기본값으로 두고 나중에 줄여도 됩니다.
6. Create를 누르면 sk-… 로 시작하는 키가 나타납니다. 이 화면에서만 전체 값을 볼 수 있으니 바로 복사해 보관합니다.

참고: OpenAI API 요금은 ChatGPT 구독과 별개로, 쓴 만큼 크레딧에서 빠집니다. 처음엔 소액만 충전하고 사용량을 확인하며 쓰세요.


C. 프로그램에 넣고 확인

1. 이 프로그램 설정에서 API 제공사를 방금 키를 만든 곳(OpenAI 또는 Gemini)으로 선택합니다.
2. API Key 칸에 복사한 키를 붙여넣습니다. 앞뒤 공백이 들어가지 않게 주의합니다.
3. 모델 새로고침을 누른 뒤 모델을 하나 고릅니다.
4. 설정 저장을 누릅니다. 두 제공사 키는 따로 저장되므로, 둘 다 넣어두고 제공사만 바꿔 쓸 수도 있습니다.
5. 긴 문서 대신 짧은 문장(예: 今日はとても静かな夜だった。)으로 먼저 테스트해 정상 동작을 확인합니다.

API 키는 비밀번호처럼 다룹니다. GitHub·블로그·채팅방·스크린샷에 올리지 말고, 제작자에게도 보내지 마세요. 유출이 의심되면 발급 사이트에서 그 키를 삭제하고 새 키를 만들어 다시 입력합니다. (오류가 날 때 점검할 항목은 "10. 오류 메시지 확인" 참고)

## 3. 비용 안내

OpenAI API 사용 요금은 일반 ChatGPT 구독과 별도로 처리됩니다. ChatGPT Plus, Pro 등을 구독 중이어도 API 사용량에 따른 비용이 따로 발생할 수 있습니다.

사용 전 OpenAI Platform의 Billing 페이지에서 결제 상태와 사용 한도를 확인합니다.

- Billing: https://platform.openai.com/settings/organization/billing
- Usage: https://platform.openai.com/usage
- Pricing: https://openai.com/api/pricing/

Gemini API는 새 계정이 Free Tier에서 시작합니다. Free Tier는 모델별 무료 사용 한도(분당·일일 요청 수, 분당 토큰 수) 안에서 무료로 사용할 수 있으며, 무료 사용 콘텐츠는 Google 제품 개선에 사용될 수 있습니다. 무료로 가볍게 쓰려면 한도가 넉넉한 Flash 계열 모델(예: gemini-2.5-flash)을 권장합니다. 정확한 한도와 데이터 처리 조건은 Google AI Studio와 Gemini API 안내에서 확인합니다.

긴 원문을 한 번에 번역하면 요청량이 늘어납니다. 처음에는 `1회 번역 글자수 제한`을 3000자 전후로 두고, 장면이나 문단 단위로 나누어 번역하는 것을 권장합니다.

## 4. 처음 실행할 때

1. 프로그램을 실행합니다.
2. `API 제공사`에서 OpenAI 또는 Gemini를 선택합니다.
3. 선택한 제공사의 API 키를 입력합니다.
4. `모델 새로고침`을 누릅니다.
5. 모델을 선택합니다.
6. `1회 번역 글자수 제한`을 설정합니다.
7. `CoC 7판 참고 메모 사용` 여부를 선택합니다.
8. `설정 저장`을 누릅니다.

저장된 API 키를 지워야 할 때는 설정 영역의 `API 키 삭제`를 누릅니다. 이 기능은 화면 입력칸만 비우는 것이 아니라 PC의 사용자 설정 파일에 저장된 OpenAI/Gemini 키 값도 함께 비웁니다.

API 키는 발급 사이트에서 다시 전체 값을 확인할 수 없는 경우가 있습니다. 삭제하기 전에 따로 보관해 두었는지 확인합니다. 보관하지 않았다면 새 API 키를 발급해야 할 수 있습니다.

모델 목록은 API 키를 입력하고 `모델 새로고침`을 누르기 전에는 비어 있습니다. 새로고침하면 선택한 제공사가 현재 제공하는 모델만 나타나므로, 단종된 모델은 자동으로 빠지고 새 모델은 자동으로 추가됩니다. 별도의 업데이트 없이 항상 최신 목록을 사용할 수 있습니다. 모델을 고르기 전에는 `번역 실행` 버튼이 비활성화됩니다. 예전에 쓰던 모델이 새 목록에 없으면 다시 선택하라는 안내가 표시됩니다.

상단의 번역 모드 선택값은 저장되어 다음 실행 때도 기본값처럼 사용됩니다. 테마도 상단에서 선택할 수 있으며, 기본값인 라일락 민트와 블루, 핑크, 그린, 다크 모드를 지원합니다. 상단의 `본문 크기` 조절(- / +)로 원문·출력문·번역 결과·교정 미리보기의 글자 크기를 -5pt에서 +5pt까지 조정할 수 있으며, 이 값도 저장됩니다.

## 5. 기본 사용 방법

1. 일본어 시나리오에서 번역할 부분을 복사합니다.
2. `일본어 원문` 칸에 붙여넣습니다.
3. 문맥이 필요한 경우 `보조 메모`에 이름, 호칭, 관계, 고유명사 표기, 독음 등을 적습니다.
4. 번역 모드를 선택합니다.
5. `번역 실행`을 누릅니다.
6. 결과를 확인한 뒤 필요한 항목의 `복사` 버튼이나 `전체 복사` 버튼을 사용합니다.

번역 중 입력을 잘못 넣었거나 요청을 멈추고 싶을 때는 `번역 중지`를 누릅니다. 중지되면 상태 영역에 `번역을 중지했습니다.`라고 표시됩니다.

## 6. 보조 메모 작성법

보조 메모에는 번역기가 원문만으로 알기 어려운 정보를 적습니다.

예시:

```text
灯 春乃（토모리 하루노）
灯은 인물명으로 쓰일 때 토모리로 번역.
PC와 KPC는 같은 동아리 출신.
星灯亭은 세이토정으로 표기.
호칭은 원문 관계성을 유지.
```

보조 메모의 고유명사는 원문에서 실제 이름이나 고유명사로 쓰인 경우에만 우선 적용됩니다. 같은 한자가 일반 단어로 쓰인 경우에는 의미에 맞게 번역됩니다.

## 7. 번역 모드

`원문 충실`은 원문의 구조, 정보 순서, 조건문, 단서 표현을 최대한 유지합니다. 판정문, 단서, 핸드아웃, 규칙 설명에 적합합니다.

`자연스러운 번역`은 한국어 문장으로 읽기 좋게 다듬습니다. 다만 대사는 말투, 호칭, 관계성을 보존하기 위해 지나치게 의역하지 않습니다.

`핸드아웃 보존`은 편지, 일기, 신문 기사, 조사 자료처럼 정보 순서와 표현 보존이 중요한 문장에 적합합니다. 고유명사는 가능한 한 원문을 함께 남깁니다.

`CoC 7판 메모 중심`은 번역과 함께 룰 표현, 판정 표현, 기능명, 특성치, 대항 판정, 명백한 단서를 더 적극적으로 찾아 설명하는 모드입니다. 이 모드는 결과 영역의 `CoC 7판 참고 메모` 칸과 구분됩니다. `CoC 7판 메모 중심`은 번역 방식이고, `CoC 7판 참고 메모`는 결과를 표시하는 칸입니다.

## 8. CoC 관련 처리 기준

기본 처리 기준은 다음과 같습니다.

- `KPC`는 그대로 표기합니다.
- `探索者`는 `탐사자`로 번역합니다.
- `目星`는 `관찰력` 관련 참고 메모로 처리합니다.
- `聞き耳`는 `듣기` 관련 참고 메모로 처리합니다.
- `図書館`은 `자료조사` 관련 참고 메모로 처리합니다.
- `アイデア`는 `지능 판정` 관련 참고 메모로 처리합니다.
- `幸運`은 `행운` 관련 참고 메모로 처리합니다.

신화 생물·신격 이름은 한국 정발(초여명 7판 수호자 룰북) 명칭으로 자동 변환됩니다. 예: `深きもの`→`심해인`, `バイアクヘー`→`비야키`, `ヨグ＝ソトース`→`요그 소토스`. 내장 목록에 없는 이름은 음역한 뒤 `고유명사/호칭 메모`에 `정발 명칭 확인 필요`로 표시되므로, 직접 확인해 보정할 수 있습니다.

TRPG 진행·세션 용어도 자동 변환됩니다. 예: `KP`→`키퍼`, `HO`→`핸드아웃`, `秘匿HO`→`은닉 핸드아웃`, `ボイセ`→`보이스 세션`, `完テキ`→`완전 텍스트 세션`, `半テキ`→`반텍스트 세션`. `HO1`, `HO2`처럼 번호가 붙은 핸드아웃 라벨은 그대로 유지됩니다.

CoC 서적 약칭도 정식 서적명으로 자동 변환됩니다. 예: `マレモン`→`말레우스 몬스트로룸(マレウス・モンストロルム)`처럼 한국 정발본이 있으면 한국어 제목과 일본 원제를 함께 표기합니다. 한국에 정발되지 않은 서적(예: `クトゥルフ2015`, `怪物図鑑`)은 일본어 제목 그대로 출력합니다. 서적 옆 페이지 표기(예: `p.212`)는 원문이 가리키는 일본판 기준이므로 그대로 둡니다.

고유명사나 용어에 원문을 함께 적는 병기(예: `푸른 파일(ブルーファイル)`)는 처음 한 번만 하고, 같은 용어가 다시 나오면 한국어 표기만 사용합니다.

자동 확정이 어려운 항목은 `검토 필요 항목`에 표시됩니다. 대표적으로 피해 보너스, 체구, 이동력, 광기 처리, 추격 규칙, 주문, 크리처 스탯, 대항 판정이 여기에 해당합니다.

## 9. 문맥 교정기 사용법

문맥 교정기는 일본어 번역 도구가 아니라, 이미 한국어로 된 시나리오 문장을 정리하는 도구입니다. 번역기에서 받은 결과나 직접 쓴 한국어 시나리오를 GM이 읽기 좋게 다듬고, 지칭(탐사자/PC 등)을 통일하고, 대사와 서술을 분리하는 데 사용합니다. 상단의 `문맥교정기` 버튼을 누르면 이 화면으로 이동합니다.

화면 구성은 다음과 같습니다.

- `교정 원문`: 다듬을 한국어 문장을 붙여넣는 칸입니다. `번역문 가져오기`를 누르면 번역기 결과를 바로 가져옵니다.
- `출력문`: 교정 결과가 표시되는 칸입니다. 직접 수정할 수도 있습니다.
- `미리보기`: 출력문을 `【서술 NN】`, `【대사 NN】` 블록 카드로 나누어 보여 줍니다. 카드별 `수정`/`복사` 버튼을 제공합니다.

버튼은 두 종류로 구분됩니다.

- 채워진 버튼: AI를 호출하는 기능입니다. 시간과 API 비용이 발생합니다.
- 외곽선 버튼: AI 없이 즉시 처리되는 로컬 기능입니다. API를 사용하지 않습니다.

### ① 지칭 변환 설정

`찾을 지칭`에 바꾸고 싶은 단어를 쉼표나 줄바꿈으로 구분해 적고(예: `탐사자, 탐사자님, PC, 플레이어`), `바꿀 지칭`에 원하는 표현(예: `당신`, PC 이름, `형사`)을 적은 뒤 `호칭만 적용`을 누릅니다. 이 기능은 로컬에서 즉시 처리됩니다.

- `대사 안 지칭도 변경`을 켜면 「」 안의 대사에 있는 지칭도 함께 바꿉니다.
- `반복 지칭 생략 허용`을 켜면 문맥상 자연스럽게 반복되는 지칭을 적절히 생략합니다.
- `KPC`는 기본 변환 대상에서 제외되며, `찾을 지칭`에 직접 입력했을 때만 변환됩니다.

### ② 문장·문맥 정리 (API)

AI가 문장을 다듬는 기능입니다. 정리 방식을 하나 골라 누릅니다.

정리 대상:

- `GM 지문`: 전체 원문을 한국어 GM 지문으로 정리합니다. 서술은 자연스럽게 다듬고, 대사는 보수적으로만 정리합니다.
- `대사 유지`: 대사는 API에 보내지 않고 원문 그대로 유지합니다. 서술 블록만 선택한 보강 강도로 정리합니다.

서술 보강:

- `없음`: 정보 보존과 번역체·요체·화자체 정리만 수행합니다. 원문이 다소 비문이어도 구조를 크게 새로 쓰지 않습니다.
- `보통`: 끊긴 흐름, 생략된 주어, 직역투 문장 연결을 보완합니다. 비문은 의미가 흔들리지 않는 범위에서 고칩니다.
- `강하게`: 원문 근거 안에서 문장 재배열, 결합, 분리, 장면 흐름 보완을 더 강하게 허용하고 비문을 적극 교정합니다.

별도 기능:

- `화자 개입 제거`: 작가가 독자·플레이어에게 직접 말하는 표현을 없애고 GM 지문형 문장으로 바꿉니다.

교정 중 멈추고 싶으면 `교정 중지`를 누릅니다. 교정 결과의 서술/대사 분리는 AI가 아니라 프로그램이 자동으로 라벨을 붙여 미리보기에 정리합니다.

### ③ 형식 정리 (즉시)

AI 없이 즉시 처리되는 기능입니다.

- `줄바꿈만`: 문장을 줄 단위로 정리합니다.
- `대사/서술 분리`: 대사와 서술을 분리해 `【대사 NN】`, `【서술 NN】` 라벨을 붙입니다.
- `대사만 추출` / `서술만 추출`: 대사 또는 서술 블록만 골라냅니다.
- `번역문 가져오기`: 번역기 결과를 교정 원문 칸으로 가져옵니다.

이미 라벨이 붙은 문장에 같은 기능을 다시 눌러도 라벨이 중복으로 쌓이지 않습니다. 문맥 교정기는 번역기와 같은 API 제공사·키·모델을 공유하므로, 번역기에서 설정을 저장해 두면 교정기에서도 그대로 사용할 수 있습니다.

## 10. 오류 메시지 확인

오류 메시지에는 현재 선택한 제공사 이름이 함께 표시됩니다.

`OpenAI API 키를 확인하세요.` 또는 `Gemini API 키를 확인하세요.`가 표시되면 선택한 제공사의 `API Key` 칸을 확인합니다. 키를 입력하지 않았거나, 키 앞뒤에 공백이 있거나, 오래된·삭제된 키일 수 있습니다. 필요하면 새 키를 만들어 다시 입력하고 `설정 저장`을 누릅니다. 제공사를 바꿨다면 그 제공사의 키가 입력되어 있는지도 확인합니다.

`모델명을 확인하세요.`가 표시되면 모델을 선택하지 않았거나, 예전에 쓰던 모델이 단종된 경우입니다. `모델 새로고침`을 누른 뒤 현재 API 키에서 사용할 수 있는 모델을 선택합니다. Gemini는 `generateContent`를 지원하는 모델만 목록에 표시됩니다.

OpenAI에서 `API 사용 한도 또는 크레딧을 확인하세요...`가 표시되면 OpenAI Platform의 Billing, Usage, Limits 상태를 확인합니다. 결제 수단이 없거나, 크레딧을 모두 사용했거나, 설정한 사용 한도에 도달했을 수 있습니다.

Gemini에서 `Gemini 무료 사용 한도(분당/일일 요청)를 초과했을 수 있습니다...`가 표시되면 잠시 후 다시 시도하거나 Google AI Studio에서 사용량을 확인합니다. 무료 한도는 모델별 분당·일일 요청 수 제한이 있어, 짧은 시간에 여러 번 요청하면 이 메시지가 나타날 수 있습니다.

`Gemini 응답 형식을 확인하세요.`가 표시되면 Gemini가 텍스트를 정상적으로 반환하지 못한 경우입니다. 잠시 후 다시 시도하거나 다른 모델을 선택해 봅니다.

`입력 글자수가 제한을 초과했습니다.`가 표시되면 원문을 더 짧게 나누거나 `1회 번역 글자수 제한`을 조정합니다.

`네트워크 연결을 확인하세요.`가 표시되면 인터넷 연결, VPN, 보안 프로그램, 회사·학교 네트워크 제한 여부를 확인합니다.

오류가 반복되면 설정 패널 아래 `오류 로그` 영역을 활용합니다. `폴더 열기`로 로그가 저장된 폴더를 열고, `복사`로 최근 로그를 클립보드에 담고, `삭제`로 로그 파일을 비울 수 있습니다. 로그는 내 PC에만 저장되며 자동으로 전송되지 않습니다. API 키, 입력 원문, 번역·교정 결과 전문은 로그에 기록되지 않으므로, 문제를 문의할 때 로그를 그대로 전달해도 안전합니다(전달 전 내용을 직접 확인할 수 있습니다).

## 11. 보안 및 배포 안내

API 키는 본인만 접근할 수 있는 환경에서 보관합니다. 프로그램은 사용자의 PC에 설정을 저장하며, 제작자가 API 키를 제공하거나 사용 요금을 대신 부담하지 않습니다.

다른 사람에게 프로그램을 전달할 때는 본인의 API 키가 들어간 상태로 배포하지 않습니다. 배포받은 사람은 각자 자신의 OpenAI 또는 Gemini 계정, API 키, 사용량 또는 결제 설정을 준비해야 합니다.

공용 PC에서 사용한 뒤에는 프로그램 설정의 API 키를 지우거나 각 제공사 페이지에서 해당 키를 삭제합니다. 키 노출이 의심되면 키 관리 페이지에서 기존 키를 삭제하고 새 키를 만들어 프로그램에 다시 입력합니다.

업데이트 확인은 GitHub에 공개된 최신 버전 정보 파일만 확인합니다. 프로그램은 업데이트 파일을 자동으로 다운로드하거나 실행하지 않습니다. 새 버전이 있으면 안내창에서 다운로드 페이지를 열 수 있으며, 교체나 설치는 사용자가 직접 진행합니다.

본인이 사용하던 프로그램 폴더를 다시 압축해서 다른 사람에게 공유하지 마십시오. 다른 사람에게 전달할 때는 제작자가 제공한 배포용 exe 또는 배포용 압축파일만 공유하십시오. API 키는 각 사용자가 직접 발급하고 직접 입력해야 합니다.

무설치판을 새 버전으로 교체할 때는 프로그램을 완전히 종료한 뒤 새 `CST-버전-portable.exe` 파일을 사용합니다. 설치형 버전을 사용할 경우에는 `CST-Setup-버전.exe`를 실행해 설치합니다. 두 배포 방식 모두 같은 Windows 계정에서는 기존 설정과 API 키가 유지됩니다.
